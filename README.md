# Sundown

**Animated & Responsive Landing Page** built with HTML, CSS, and JavaScript — featuring smooth scrolling and an interactive UI.

## 🚀 Overview

**Sundown** is a fully responsive and visually engaging landing page designed to deliver a smooth user experience across devices. It incorporates modern frontend techniques, smooth scroll animations, and intuitive interactions to create an immersive browsing experience.

This project is ideal for showcasing landing page design skills with animation effects and responsive layouts.

## 💡 Features

- ✅ **Responsive Design** — adapts flawlessly to mobile, tablet, and desktop viewports  
- ✅ **Smooth Scrolling** for enhanced user interaction  
- ✅ **Interactive UI Elements** for engaging user experience  
- ✅ **Built with Core Web Technologies** — HTML, CSS, and JavaScript  
- ✅ **Lightweight & Easy to Customize**  

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML       | Page structure |
| CSS        | Layout, styling & animations |
| JavaScript | Smooth scrolling & DOM interactions |
